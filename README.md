# Fabrication-toolkit-for-all
Free, open-source KiCad plugin to export manufacturing files (Gerber, drill, BOM, PNP) for PCB manufacturers worldwide. Includes one-click file import to the DIYIPCB PCB ordering page. Supported by DIYIPCB.
Fabrication Toolkit for All is a free, open-source KiCad plugin that generates standard PCB manufacturing files, including Gerber files, drill files, BOM files and pick-and-place files.
Use the exported files with your preferred PCB manufacturer, or import them directly into the DIYIPCB ordering page.Manufacturer-specific file naming, BOM formats and placement conventions may require adjustments.
